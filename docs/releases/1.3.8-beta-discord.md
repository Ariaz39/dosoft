## Message 1/3 — annonce

# 🧪 DOSOFT 1.3.8 BÊTA EST DISPONIBLE

Cette bêta regroupe l'ensemble des évolutions réalisées depuis la **1.2.2**.
Elle est publiée pour effectuer une dernière campagne de tests avant la future
version stable.

### ✨ Principales nouveautés
- Sélection séparée pour **Dofus Unity**, **Dofus Rétro** et **Wakfu**.
- Nouvelle barre globale de personnages : formats horizontal, vertical,
  compact et fantôme.
- Changement rapide d'équipe et raccourcis plus fiables.
- Auto-focus Dofus Rétro configurable à partir des notifications Windows.
- Rangement automatique des fenêtres Rétro en plein écran ou en mosaïque.
- Sauvegarde et restauration de l'affichage Dofus avec le profil
  `JEU CLASSIQUE`.
- Assistant OBS complet et connecteur **0.3.1**.
- Streamdeck flottant personnalisable : micro, caméra, pause, scènes et sources.
- Traductions : français, anglais, espagnol, portugais et allemand.
- Nombreuses corrections de stabilité, de détection et de performances.

📋 Notes complètes :
<https://github.com/LuframeCode/dosoft/releases/tag/v1.3.8-beta.1>

## Message 2/3 — téléchargement et conditions

## 📥 Téléchargement

**Setup recommandé :**
<https://github.com/LuframeCode/dosoft/releases/download/v1.3.8-beta.1/Dosoft_BETA_Setup_v1.3.8.exe>

> ⚠️ **CONDITIONS DE LA BÊTA**
> - Version destinée aux tests : utilisez-la d'abord **hors stream**.
> - Windows 10/11 uniquement.
> - Connecteur testé avec **OBS Studio 32.x 64 bits**.
> - Fermez complètement DOSOFT et OBS avant l'installation.
> - Une sauvegarde de `%APPDATA%\\DOSOFT` est conseillée avant la mise à jour.
> - Le setup peut être installé par-dessus la version précédente et conserve
>   normalement les profils.
> - Les mises à jour restent manuelles pendant la bêta.

### 🛡️ Avertissement Windows
Le programme est distribué en notre nom propre et n'est pas encore signé avec
un certificat commercial. SmartScreen peut donc afficher un avertissement.

Téléchargez la bêta **uniquement depuis la release GitHub officielle** et
contrôlez `SHA256SUMS.txt` en cas de doute.

||L'option avancée « Superposer les raccourcis » désactive une sécurité contre
les répétitions de touches. Son utilisation est déconseillée et les plantages
provoqués spécifiquement par cette option ne sont pas pris en charge.||

## Message 3/3 — retours de test

## 🐞 Signaler un problème

Merci de publier chaque problème dans le canal bêta prévu à cet effet avec :

- la version `DOSOFT 1.3.8 BETA` ;
- votre version de Windows ;
- le moteur utilisé : Unity, Rétro ou Wakfu ;
- votre version d'OBS si le problème concerne le connecteur ;
- les étapes exactes permettant de reproduire le problème ;
- une capture ou une courte vidéo si possible ;
- les journaux DOSOFT/OBS utiles après avoir masqué toute donnée personnelle.

> Un ticket = un problème. Évitez les messages « ça ne marche pas » sans étapes
> de reproduction : ils ne permettent pas de diagnostiquer le bug.

### Limites déjà connues
- Auto-focus Wakfu non proposé comme fonction stable.
- Auto-focus Rétro dépendant des notifications Windows du jeu.
- Avertissement SmartScreen possible car les binaires ne sont pas signés.
- Pas de mise à jour automatique pendant cette bêta.

Merci à toutes les personnes qui testent cette version 💚
